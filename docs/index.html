The problem, in one paragraph

You are building a biosecurity screen: a panel of a few hundred to a thousand known toxin proteins, frozen-PLM embeddings, cosine k-nearest-neighbor retrieval, and a vote. Recent literature shows this works well on average. This compendium shows that on the queries that matter most — those most distant from any panel member, exactly where novel threats live — the pipeline fails systematically, while still looking confident from the outside. At the largest scale tested, with a panel of 1,000, close-stratum F1 is 0.866 while distant-stratum F1 is 0.120. The cliff grows with model scale and panel size. We call this the homology cliff.

Four pre-registered rescues — Mahalanobis whitening, Fisher-Rao whitening, a stratified metric cascade, and Mapper-biased panel augmentation — are rejected at their pre-registered hypotheses. One rescue survives: a cheap, panel-only supervised linear projection of the embedding space, fit in seconds of CPU time. The deployment consequence is direct: apply the projection, and even then route every distant-stratum positive to human review.

Reproduce it yourself

Every claim traces to a committed artifact. Two checks run in seconds on a fresh clone with no large-file download:

1 · Regenerate the summary figure from committed evidence

# reads only data/results_summaries/v3_final.txt + calibration_results.json
pip install matplotlib
python scripts/build_summary_figure.py
→ wrote figures/cliff_summary.png

2 · Verify the headline numbers (no Git LFS required)

python -c "import json; d=json.load(open('data/results_summaries/calibration_results.json')); print('ECE close/distant:', d['close']['ECE'], d['distant']['ECE'])"
→ ECE close/distant: 0.069 0.294

python -c "import json; d=json.load(open('data/results_summaries/cross_family_partition.json')); print('within / cross / evaluable:', d['within_family'], d['cross_family'], d['n_evaluable'])"
→ within / cross / evaluable: 0 20 20

3 · Full reproduction from the 9,360 cells (requires Git LFS)

git lfs pull                              # ~188 MB of binary evidence
pytest tests/ -v                          # schema + invariant checks
python code/analyses/v3_aggregate.py      # regenerates the headline table

Integrity is machine-checked on every push: a SHA256 manifest over 9,475 files, two byte-locked pre-registration hashes, and headline-number spot-checks all run in CI. See REVIEWER.md for the full five-command verification.

The five papers

  • 1 · Homology Cliff and Its Rescue
    Cliff confirmed (+0.745 gap at t30); full-pool null passes 300/300; rescue via learned projection wins 18/18.
  • 2 · Four Failed Rescue Attempts
    Mahalanobis, Fisher-Rao, cascade, Mapper-augmentation — each rejected at its pre-registered hypothesis.
  • 3 · Calibration Collapse
    ECE 0.069 → 0.294 close→distant; 0 of 3 highest-confidence distant predictions correct.
  • 4 · Methods and Pre-Registrations
    The 9,360-cell factorial template, the seed-variance gate, and the SHA256 pre-registration pattern.
  • 5 · Cross-Family and Mapper Topology
    All 20 evaluable distant false alarms are cross-family (Wilson 95% CI on the within-family rate [0%, 17%]).

Evidence and integrity

Committed, not just claimed

9,360 per-cell results as .npz files with bootstrap confidence intervals; ESM-2 t6/t12/t30 embeddings; Pfam annotations; aggregated summaries. Every file has a SHA256 entry in the manifest.

Pre-registered before execution

Hypotheses and success criteria were committed and SHA256-locked before the corresponding experiments ran; the harness recomputes the hash at runtime and aborts on drift.

Honest scope. This is a v1.4.7 release with a transparent self-audit (PROBLEMS.md, STATUS.md). One open item is documented in full: a robustness re-run of the Mapper-augmentation attempt under untruncated node membership, with a ready-to-run harness. Open limitations are stated, not hidden — the same pre-registration discipline applies to what remains.
