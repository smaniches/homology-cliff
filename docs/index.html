The problem, in one paragraph

You are building a biosecurity screen: a panel of a few hundred to a thousand known toxin proteins, frozen protein-language-model embeddings, cosine k-nearest-neighbor retrieval, and a vote. Recent literature shows this performs well on average. This work shows that on the queries that matter most — those most distant from any panel member, exactly where a novel threat would sit — the pipeline fails systematically, while still appearing confident from the outside. At the largest scale studied here, with a panel of 1,000, close-stratum F1 is 0.866 while distant-stratum F1 is 0.120. Within the studied range, the gap grows with model scale and panel size. We call this the homology cliff.

The distant-stratum failure is not merely lower accuracy: the classifier is confidently wrong there. Expected Calibration Error quadruples, and in the highest-confidence distant bin the positive-prediction precision is 3 of 44. A downstream filter that routes high-confidence positives to automated action would route false alarms to automation precisely where human review is most needed.

How the cliff was established

The central question a careful reader asks is: is this a real effect, or an artifact of how the data was sliced? The study was designed to answer that before it was run.

  • Pre-registered factorial. 3,000 cells — 3 ESM-2 scales (t6/t12/t30) × 5 panel sizes × 5 values of k × 4 metrics × 10 seeds — each with bootstrap confidence intervals, on a 24,885-protein test set.
  • A full-pool permutation null. A matching 3,000-cell experiment permutes labels across all 24,885 proteins. With no real signal, the close−distant gap should vanish — and it does: 300 of 300 groups pass the gap-near-zero criterion (panel b). The cliff is therefore not produced by the stratification itself.
  • Label-free stratification. Queries are split by maximum cosine similarity to the panel (close ≥ 0.95, distant < 0.90), independent of their labels.
  • A seed-variance gate voids underpowered cells, so reported effects are not driven by small strata.
  • SHA256-locked pre-registrations. Each hypothesis and success criterion was committed and hashed before the experiment ran; the harness recomputes the hash at runtime and aborts if it has drifted.

What this is — and what it is not

Stated plainly, so the claims are not mistaken for more than the evidence supports.

What it is

  • A reproducible characterization of a failure mode in frozen ESM-2 (t6/t12/t30, up to 150M parameters) cosine k-NN biosecurity retrieval.
  • A controlled demonstration that the effect is not a stratification artifact (full-pool permutation null).
  • A candidate rescue and an explicit deployment recommendation.
  • Fully traceable to committed evidence — 9,360 per-cell results, a SHA256 manifest, pre-registration locks, and CI.

What it is not (yet)

  • Not a claim about all protein language models or scales: ESM-2 650M, ProtT5, SaProt, and ESM-3 are scaffolded but not yet run (this study is CPU-only).
  • Not independently replicated: a single-author, AI-assisted compendium; no third-party replication is on file yet.
  • Not a finished product: the rescue ships as a reference implementation, not a packaged tool.
  • The cross-family mechanism is at n=20 evaluable cases at one seed (Wilson 95% CI on the within-family rate [0%, 17%]) — suggestive, not definitive.
  • The dataset's label-curation rule is withheld per dual-use guidance.

The open items are tracked in the open: see PROBLEMS.md (self-audited errors and deferrals) and STATUS.md (current verification state). One scientific item — a robustness re-run of the Mapper-augmentation attempt under untruncated node membership — ships with a ready-to-run harness.

The rescue, and the deployment recommendation

Four rescues were pre-registered and rejected at their stated hypotheses: Mahalanobis whitening, Fisher-Rao whitening, a stratified cosine-then-Mahalanobis cascade, and Mapper-biased panel augmentation. One survives: a supervised linear projection of the embedding space, fit on the panel alone in seconds of CPU time. It wins pooled F1 in 18 of 18 factorial groups and improves distant-stratum F1 by about 47% relative at the largest scale studied.

The honest operational consequence: apply the projection, and even then route every distant-stratum positive to human review. The rescue narrows the gap; it does not make the distant stratum trustworthy on its own.

Reproduce it yourself

Every claim traces to a committed artifact. Two checks run in seconds on a fresh clone with no large-file download:

1 · Regenerate the summary figure from committed evidence

# reads only data/results_summaries/v3_final.txt + calibration_results.json
pip install matplotlib
python scripts/build_summary_figure.py
→ wrote figures/cliff_summary.png

2 · Verify the headline numbers (no Git LFS required)

python -c "import json; d=json.load(open('data/results_summaries/calibration_results.json')); print('ECE close/distant:', d['close']['ECE'], d['distant']['ECE'])"
→ ECE close/distant: 0.069 0.294

python -c "import json; d=json.load(open('data/results_summaries/cross_family_partition.json')); print('within / cross / evaluable:', d['within_family'], d['cross_family'], d['n_evaluable'])"
→ within / cross / evaluable: 0 20 20

3 · Full reproduction from the 9,360 cells (requires Git LFS)

git lfs pull                              # ~188 MB of binary evidence
pytest tests/ -v                          # schema + invariant checks
python code/analyses/v3_aggregate.py      # regenerates the headline table

Integrity is machine-checked on every push: a SHA256 manifest over 9,475 files, two byte-locked pre-registration hashes, and headline-number spot-checks all run in CI. See REVIEWER.md for the full five-command verification.
