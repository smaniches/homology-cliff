## Re-executing the confirmatory computation (optional)

`code/analyses/run_cross_family_partition_10seed.py` writes its output to `data/results_summaries/cross_family_partition_10seed.json` — the sealed confirmatory result. Do not invoke the runner bare in a working checkout: that would overwrite the canonical file. Use the guarded recipe below, which refuses to start unless the committed file matches the sealed SHA256, snapshots it before execution, restores it in **all** cases (success, mismatch, crash, interrupt), and fails unless the regenerated bytes are identical to the sealed result. Re-execution requires the three frozen Git-LFS inputs and FAISS CPU.

```bash
set -euo pipefail

git lfs pull --include="data/embeddings/embeddings_t30.npy,data/sequences/proteins_25k_sequences.json,data/annotations/proteins_25k_pfam.json"
pip install "numpy==2.4.6" "faiss-cpu==1.15.0"
python scripts/ci/verify_prereg_locks.py
python scripts/ci/verify_manifest.py

RESULT="data/results_summaries/cross_family_partition_10seed.json"
SEALED_SHA256="332b939622ac2a174124f5378d74d2df074d66561654c7b84e55002608677b7d"

# Refuse to start from anything but the sealed canonical bytes.
echo "${SEALED_SHA256}  ${RESULT}" | sha256sum -c -

# Snapshot the sealed result; the trap restores it however the run ends,
# so the canonical file cannot be silently replaced and git status stays clean.
SNAPSHOT="$(mktemp)"
cp "${RESULT}" "${SNAPSHOT}"
trap 'cp "${SNAPSHOT}" "${RESULT}"; rm -f "${SNAPSHOT}"' EXIT

python code/analyses/run_cross_family_partition_10seed.py

REGENERATED_SHA256="$(sha256sum "${RESULT}" | awk '{print $1}')"
if [ "${REGENERATED_SHA256}" != "${SEALED_SHA256}" ]; then
    echo "FAIL: regenerated ${REGENERATED_SHA256} != sealed ${SEALED_SHA256}" >&2
    exit 1
fi
echo "OK: regenerated result is byte-identical to the sealed confirmatory result"
```

The runner verifies the locked inputs, requires seed 20260410 to reproduce the committed original detail exactly, then evaluates all ten fixed seeds. The panel seed is the robustness unit; recurring accession appearances must not be pooled into an independent-trials binomial interval.
